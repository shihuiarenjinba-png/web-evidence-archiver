Web Evidence Archiver — はじめに

URLのメモ帳ではありません。許可したWebページを取得時点のHTML・PNG・PDF・metadata・SHA-256 manifestとしてローカル保存します。

最初にやること

  1. EXEを起動し「新規作成」を選びます。
  2. 保存URL、許可ホスト、出力先を入力します。
  3. 新しい設定として保存します。
  4. 保存済み設定を選び、取得を実行します。
  5. HTML、PNG、PDF、metadata、manifestと出力フォルダーを確認します。

入力例

設定名 Example Web Capture
URL https://example.com/
許可ホスト example.com

出力されるもの

指定した出力先へHTML、PNG、PDF、metadata、SHA-256 manifestを保存します。取得結果と実際の保存先は完了画面で確認してください。

既存設定へURLを追加

  1. 設定JSONを読み込みます。
  2. URL欄の一番下へ新URLを1行追加します。
  3. 既存URLが残っていることを確認します。
  4. 更新を保存します。更新前backupが作成されます。
  5. 元設定を残す場合は別名保存を選びます。

設定JSONは「何を取得するか」の設定です。Web記録は別の出力フォルダーに保存される実成果物です。

任意メモ追記

既存の.txt／.mdを指定すると、既存本文を保持した末尾へ取得日時、URL、保存先、manifest、完了状態を追記します。空ファイルなら先頭から記載します。DOCX／XLSX／PDFへは追記しません。

よくあるエラー

  • HTTPS以外、許可ホスト不一致、HTTP error、timeout、blocked resourceは結果とmanifestで確認します。
  • ログイン、CAPTCHA、DRM、動画、強いbot対策、複雑な動的ページは正しく保存できない場合があります。
  • 出力先へ書き込めない場合は別フォルダーを選びます。
法的証拠能力、ページの完全再現、外部サイトの継続提供を保証しません。
